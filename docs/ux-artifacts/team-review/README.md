## Recurring findings

Whole-map Fit is useful for orientation but must not replace readable focused content. Table and Graph should share exact scope; contextual actions must not obstruct selected nodes. Model configuration needs one retained draft across its representations. Evidence review should show the captured inputs beside the judgment, while keeping current state and immutable captures distinct.

Later work introduced readable focus/overview controls, exact captured-input versions, change-aware context and retained task ownership. The earlier reports remain historical assessments, not current release gates or evidence of representative-user acceptance.
