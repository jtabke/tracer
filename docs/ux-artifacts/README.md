# Design studies and research artifacts

These folders preserve design exploration and its evidence. They are separate from the application in `ui/` and are not a feature backlog. The [UX plan](../ux-plan.md) owns current direction; each study's README records its scope, status and limitations. Historical selection or passing tests does not imply acceptance of a later design.

## Start here

[Map-first](map-first/README.md) records the selected UI's integration. Its renderer now lives in `ui/map/` and is the one native application interface for all examples. Its package is a compatibility launcher; root checks include its moved projection tests. The maintained [workbench candidate](product-identity/README.md) demonstrates native authoring, shared Graph/Matrix/History context and evidence assessments within the selected visual combination; other folders below remain historical research.
