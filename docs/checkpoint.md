## Independent critique and repairs

The reviewer read source, baseline snapshot, logs and screenshots but could not independently execute tests. Its initial verdict was BLOCK pending two P1 repairs; parent repaired and verified these, without claiming a second independent approval:

1. **Review guard:** Evidence rationale now captures receipt/token when drafted, survives refresh, and cannot silently submit against changed inputs. Explicit refreshed-input adoption or discard is required; changing receipt requires draft discard confirmation. Both scale journeys test input drift after rationale capture and disabled submission before adoption.
2. **Schema recovery:** Explicit connection-draft discard reconciles the meaning and target type to the current schema, clearing search/page/draft. Recovery controls remain usable without a definition. A browser test removes the chosen meaning, refreshes, adopts schema v2 and successfully creates its replacement connection without changing the focused item.
3. **Stacked selection:** Accepted item selection focuses the detail heading, resets its scroll and reveals it at stacked widths. Keyboard/narrow tests assert visible focused headings.
4. **Dense-context discovery:** A heading-level counted Browse connections shortcut focuses/reveals the existing bounded connection section. Narrow screenshot verifies filter/count discovery without scrolling through creation controls.

Read-recovery regression additionally injects a failed Work context read, verifies retained item draft and paused saving, then verifies successful refresh restores editing without rebuilding the draft.

A minimum-Node browser run intermittently timed out **after all shared-selection assertions passed**, during fixture shutdown. Trace confirmed assertions completed in under a second and shutdown consumed the remaining timeout.
