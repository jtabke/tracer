# Selected specifications

These are deliberately retained, bounded engineering contracts—not generated run reports or a live delivery dashboard.

- [Configuration change](configuration-change-specification.json)
- [Requirement Verification](requirement-verification-specification.json)
- [Concurrent local operation](concurrent-local-specification.json) and [workload budgets](concurrent-local-budgets.json)
- [Standards applicability inventory](standards-applicability.json): design references, reviewed editions and gaps; not a clause-complete conformance claim

Files retain their captured record IDs and original evidence/reference paths. Historical run artifacts resolve through the [private register archive](../register.md#historical-evidence); moving a specification does not execute it or promote a status. Product operation does not require the private register.
