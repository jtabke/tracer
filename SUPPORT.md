# Support

Tracer is an unreleased source preview. There is no hosted service, guaranteed response time, paid support or long-term-support release.

## Report a problem

Use [GitHub issues](https://github.com/jtabke/tracer/issues) with:

- The commit (`git rev-parse --short HEAD`), Node version, operating system and startup command.
- Minimal steps, expected behavior and what actually happened.
- A fictional reproduction or sanitized error—not your working project database, source documents, credentials or full network logs.

Check [local operation and recovery](docs/guides/local-operation.md) first. For an uncertain save, inspect its original command outcome; don't repeat the write blindly. Preserve a backup before experimenting with migrations or recovery.

Feature requests should explain the engineering task and current obstacle. An issue is not implementation approval or a delivery commitment. Pull requests follow [Contributing](CONTRIBUTING.md).

For suspected vulnerabilities, follow [Security](SECURITY.md), not a public bug report containing exploit details or private data.
